# 🕊️ Carrier Pigeon Messenger

**پیام‌رسان کبوتر پیک** — پیام‌رسانی که پیام‌ها رو با کبوتر مجازی می‌فرسته!

> پیام‌ها فوری ارسال نمیشن. هر پیام توسط یک «کبوتر مجازی» با سرعت ~177 km/h حرکت می‌کنه و مدت زمان رسیدن بر اساس فاصله واقعی GPS محاسبه می‌شه.

## ✨ امکانات

- 🕊️ **کبوتر مجازی** — هر پیام با یک کبوتر فرستاده میشه
- 🗺️ **ردیابی زنده** — مسیر حرکت کبوتر رو روی نقشه ببین
- 📏 **محاسبه فاصله** — بر اساس GPS واقعی
- ⚡ **سرعت متغیر** — ±25% تغییر سرعت
- 💀 ** risk گم شدن** — 0.2% احتمال گم شدن کبوتر در مسیر
- 💬 **چت زیبا** — رابط کاربری فارسی و RTL
- ⚙️ **تنظیمات** — نام، مکان، و سفارشی‌سازی
- 📱 **اندروید + ویندوز** — از یک کد پایه

## 📸 اسکرین‌شات

| چت | ردیابی | تنظیمات |
|-----|--------|---------|
| 💬 لیست مخاطبین | 🗺️ نقشه زنده | ⚙️ پروفایل |

## 🛠 تکنولوژی

- **Flutter** 3.32+ (Dart 3.8+)
- **flutter_map** + OpenStreetMap
- **shared_preferences** برای ذخیره‌سازی
- **Material Design 3**

## 🚀 نصب و اجرا

### اندروید
1. از [Releases](https://github.com/AnishtayiN/carrier-pigeon/releases) فایل APK رو دانلود کن
2. روی گوشی نصب کن

### ویندوز
1. از [Releases](https://github.com/AnishtayiN/carrier-pigeon/releases) فایل ZIP رو دانلود کن
2. اکسترact کن و `carrier_pigeon.exe` رو اجرا کن

### کامپایل از سورس
```bash
flutter pub get
flutter run                          # اجرا روی دستگاه متصل
flutter build apk --release          # ساخت APK
flutter build windows --release      # ساخت EXE
```

## 🎮 نحوه بازی

1. **مخاطب انتخاب کن** از لیست
2. **پیام بنویس** و بفرست

4. **روی نقشه ببین** مسیر کبوتر رو
5. **امیدوار باش** گم نشه! 💀
